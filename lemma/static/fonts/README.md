# Fonts

Self-hosted so Lemma never contacts a font CDN, and inlined into downloaded lessons. Both families are licensed under the SIL Open Font License 1.1 (`OFL-Archivo.txt`, `OFL-SplineSansMono.txt`).

| Files | Family | Used for | Source |
|---|---|---|---|
| `archivo-latin-normal.woff2` | Archivo (variable, weights 400–800) | headings, running text, controls, numbers | Google Fonts v25, latin subset |
| `archivo-latin-italic.woff2` | Archivo Italic (variable, weights 400–800) | the source's words on gallery quote cards | Google Fonts v25, latin subset |
| `spline-sans-mono-latin-normal.woff2` | Spline Sans Mono (variable, weights 400–700) | the typewritten record: field labels, citations, readouts, the paper's own words | Google Fonts v13, latin subset |

Characters outside the latin subset (Greek in equations, arrows, ✓) fall back to system fonts. Arrows and checks in the interface are drawn SVG icons.
