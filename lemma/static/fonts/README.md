# Fonts

Self-hosted so Lemma never contacts a font CDN. Both families are licensed under the SIL Open Font License 1.1 (`OFL-Barlow.txt`).

| Files | Family | Source |
|---|---|---|
| `barlow-latin-{400,500,600,700}-normal.woff2`, `barlow-latin-400-italic.woff2` | Barlow | [Fontsource](https://fontsource.org/fonts/barlow) `@fontsource/barlow` 5.x, latin subset |
| `barlow-condensed-latin-{600,800}-normal.woff2` | Barlow Condensed | [Fontsource](https://fontsource.org/fonts/barlow-condensed) `@fontsource/barlow-condensed` 5.x, latin subset |

Characters outside the latin subset (Greek in equations, arrows, ✓) fall back to system fonts. Arrows and checks in the interface are drawn SVG icons.
