# Fonts

Self-hosted so Lemma never contacts a font CDN, and inlined into downloaded lessons. Both families are licensed under the SIL Open Font License 1.1 (`OFL-AtkinsonHyperlegibleNext.txt`, `OFL-Literata.txt`).

| Files | Family | Used for | Source |
|---|---|---|---|
| `atkinson-hyperlegible-next-latin-{normal,italic}.woff2` | Atkinson Hyperlegible Next (variable, weights 200–800) | everything: reading, headings, controls, numbers | Google Fonts v7, latin subset |
| `literata-latin-italic.woff2` | Literata italic (variable) | the paper's own words: quotes and paper titles | Google Fonts v40, latin subset |

Characters outside the latin subset (Greek in equations, arrows, ✓) fall back to system fonts. Arrows and checks in the interface are drawn SVG icons.
