Lemma, is a tool to learn complex topics easily in visual manner. 
It is inspired by brillant.org and 3Blue1Brown video animations.

You can use Lemma to analyze any research paper, and generate lessons from it.

Lemma can also take a topic, find the relevant sources and generate the lessons in the background. 
Use can allocate the max time to generate the high quality lessons.

The different kind of content people would like to learn

- Scientific papers
- complex concepts
- Codebases

## Scienfic papers / Complex concepts

* Gap between the existing information
* Visualisation for deeper understanding
* (Optional) Testing to make sure you understand the code concepts well enough

## Codebase

* Architecture / flow diagram 
* Run the relevant flows with different inputs
